# 古文攻略アカデミー Ver.5.2.1

公開URL: https://beep16band.github.io/kokyo/kobun-academy/?v=5.2.1

ブラウザ標準window.topと自作top関数の衝突によりホームが起動しない不具合を修正。画像データ初期化もメイン処理から分離しました。

中学生向け古文入門・高校入試対策アプリ。入門10ユニット、3学習モード、5段階ヒント、別問題による習得確認、履歴、コイン・衣装、スキップ可能な短い起動演出を実装。11〜40ユニットは準備中。

画像・CSS・問題データをindex.htmlへ同梱。外部通信不要。学習記録はこのブラウザ内に保存。設定からバックアップを読み書きできます。

ブラウザ同様の変更不可なtopプロパティを設けたNode VMで起動・学習処理30項目、オープニング終了処理7項目を検証。実ブラウザの描画検証は未実施です。
