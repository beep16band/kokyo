# 古文攻略アカデミー Ver.5.3

公開URL: https://beep16band.github.io/kokyo/kobun-academy/?v=5.3

更新内容

- 3匹を専用の透過キャラクター素材へ更新。通常・応援・考える・説明のポーズを統一し、透過マットの縁はSVGフィルターで描画時に抑制。
- 学習内容の一覧を既定表示に。検索・分類・進捗フィルター、各モードの直接開始、旅マップへの切替。
- 画面切替、ボタン波紋、ダイアログの軽いエフェクト。動きを減らす設定に対応。
- 衣装は通常＋桜・月・竹・夏祭り・紅葉・雪・学士の8セット。ホームの案内役も選択可能。
- 学びのしおり10枚、追加称号12種類、日替わり任意目標3件。達成報酬は各1回のみ。スキップだけでは回答数目標を達成しない。

入門10ユニットが学習可能。11〜40は追加予定。画像・問題・CSS・JSはindex.htmlへ埋め込み、学習記録はブラウザに保存、外部送信なし。

Node VMで学習・追加機能45項目、起動演出7項目、操作エフェクト5項目を検証。実ブラウザの描画検証は未実施。
