# 古文攻略アカデミー Ver.5.2

中学生向け古文入門・高校入試対策の学習アプリ。

公開URL: https://beep16band.github.io/kokyo/kobun-academy/

画像・CSS・問題・起動演出をindex.htmlへ埋め込み、外部サービスへの依存なしで起動します。

入門10ユニット（40ユニットのうち30は準備中）、3モード、5段階ヒント、別問題による習得確認、履歴、コイン・衣装、約4秒のスキップ可能な起動演出を実装。

学習記録はブラウザ内に保存。外部送信なし。ローカル版の記録は設定から書き出し、この公開版で読み込めます。

学習ロジック30項目・起動演出処理7項目をNode VMで検証。実ブラウザの描画検証は未実施です。
