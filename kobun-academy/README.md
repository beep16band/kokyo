# 古文攻略アカデミー Ver.5.8.0

受験生の「昨日読めなかった一文が、今日読めるようになる。」を支える古文学習アプリ。

## 今回の実装

- はじめにを全5章に再構成。指定メッセージ、学ぶおもしろさ、3段階の例文解読体験、学習開始ボタン。
- 出典から考える：6ジャンル・18作品、作品名／読み／作者の検索、ジャンルの絞り込み、作品詳細。
- 作品ごとに成立時期、作者・編者、正式な文学ジャンル、描かれる時代、100〜150字の独自紹介、特徴、読むポイント、読解観点、関連単元、参考資料。
- 7時代の年表。PCは横スクロール、スマートフォンは縦型。成立時期と描かれる時代、室町と南北朝の重なりを明示。
- 実本文6編（竹取物語・徒然草第52段・土佐日記・宇治拾遺物語「児のそら寝」・平家物語「扇の的」・万葉集巻1・28）の6ステップ演習。特徴→方針→本文→根拠→独自訳・解説。誤答時は即再挑戦可能。
- 出典・ジャンル確認クイズ6問。曖昧な特徴は作品名を一意に当てさせず読み方を問う。
- 既存3匹のキャラクターを使用。新ページ向けのSVG図版6点。既存の短い画面・ボタン効果と端末の動きを減らす設定を継承。
- 学習開始・正解・誤答・終了の励ましを複数化。履歴上の直前の誤答から再正解した場合は専用メッセージ。

## 維持した機能と記録

3モード、最大5段階ヒント、スキップ、15公開／40計画単元、既存問題、診断、今日の3問、語彙カード、学習履歴、コイン・XP・称号・着せ替えを維持。保存キー `kobun_academy_v5` と形式を変更していません。新ページの閲覧や新演習は、既存の習得判定・報酬・回答履歴に混入しません。出典演習の途中経過・クイズ回答・直近100回の完了履歴は、独立キー `kobun_academy_sources_v1` に保存します。出典ページから再開、専用JSONの書き出し・読み込みができます。外部への成績送信なし。

## ファイル

`index.html` が分割版の入口。`reading-pages.js` と `reading-pages.css` が新ページ。`data/classics.json` は18作品の編集用データ、`data/classics.js` はローカルファイルでも開ける実行用の同内容データ。`data/assets.js` は既存画像の埋め込みデータ。既存ソースは公開版から復元しました。復元に含まれなかった旧教材の独立HTMLはこの配布には含みません。

`dist/index.html` は画像・CSS・教材を全て含む単一HTMLです。今回の公開環境ではこれを `kobun-academy/index.html` に置きます。

## 公開

GitHub Pagesで既存の `kobun-academy/index.html` を `dist/index.html` に置き換えます。既存のmainブランチ・Pages設定を利用します。他フォルダーのサイトは変更しません。ルートURLはホーム、`?page=exams` は入試の出典記録、`?page=introduction` と `?page=sources` はそれぞれの新ページを直接表示します。

編集後は親フォルダーの `package.py` を実行して単一HTMLを再生成。`node tests/regression.cjs` でロジックを確認できます。検索結果なし、フィルター、誤答・再正解、390px幅の表示もブラウザで確認してください。

## 工程①（5.4.1）

`source-progress.js` で出典学習を別管理。作品ごとの途中保存、回答済み解説の復元、二重加点防止、完了履歴、予備データ回復、保存失敗時の書き出し導線を追加。従来の設定でのバックアップは既存単元専用のままです。出典の記録は出典ページから別に書き出してください。

検証：`node tests/regression.cjs` と `node tests/source-progress.cjs`。

## 工程②（5.4.2）

6ジャンル全てに短い原文演習を収録。追加した3編には学習目標、場面説明、語注と読み、独自訳、具体的な根拠の原文、断定できないことの説明、確認資料を付けました。3編とも作品名の暗記で正解できる設問にはしていません。

`data/source-exercises.json` が原文演習の編集用データ。`data/source-exercises.js` は同内容を `window.SOURCE_EXERCISE_DATA` に渡すローカル実行用ファイルです。追加・修正時は両方を同内容で更新してください。旧3編のID・正解は維持し、保存形式は変更していません。

## 工程③（5.5.0）

18作品に閲覧・練習・確認・復習の状態を表示。原文練習に対応する6作品には、練習とは異なる本文で各2問、計12問の習得確認を追加しました。全問回答後に正誤と根拠を示し、全問正解でその確認を通過します。ヒントはなく語注は使えます。未正解・スキップした問だけの復習から、全問の再確認へ進めます。復習だけの正解を習得確認済みにはしません。

本文への一歩・根拠の探偵・読み直す力・出典マスター〈入門〉の4称号を条件達成後に一度だけ獲得・選択できます。既存のコイン・XP・称号には影響しません。出典マスターは現在の6作品の確認通過であり、作品全体の理解を保証する認定ではありません。同じ確認問題を再出題する限界も画面に明記しています。

`data/source-checks.json` が別本文確認の編集用データ、`data/source-checks.js` が同内容の実行用データです。`source-growth-store.js` は追加保存項目の検証・移行、`source-mastery.js` は確認・復習・称号の画面と判定を担当します。

保存キー・versionは維持し、作品状況・確認途中・称号を任意項目として追加。旧出典記録からは練習完了だけを引き継ぎ、習得済みを自動付与しません。専用JSONの書き出し・読み込みにも新記録が含まれます。未対応12作品は紹介の閲覧記録のみで、確認教材は準備中と表示します。

検証コマンド：`node tests/regression.cjs`、`node tests/source-progress.cjs`、`node tests/source-mastery.cjs`。合計85項目合格。

## 工程④（5.6.0）

「出典から考える」に入試の出典記録を追加。兵庫県2024〜2026年度の本検査、大阪府2026年度の一般選抜A・B・C問題、計6件を公式資料と照合して収録しました。作品名・読み・地域・西暦の検索、府県・年度・作品・確認範囲の複合絞り込み、詳細、公式PDFの該当ページへのリンク、既存の作品紹介と独自の関連練習への接続を実装しています。

出典一覧だけを確認した記録と、小問の分類を確認した記録、実際の設問を確認した記録を区別。掲載がない作品を「出題なし」とは扱わず、出題予想・頻度順位も表示しません。過去問の本文・設問・解答は転載していません。作品名は校注者の名前と区別しています。

`data/exam-records.json` が編集用、同内容の `data/exam-records.js` がローカル実行用。`exam-records.js` が一覧・詳細・検索を担当します。記録には資料URL・確認日・ページ・確認対象を必須で記入し、未確認情報を推測で追加しないでください。既存のセーブへの書き込みはありません。

追加検証：`node tests/exam-records.cjs`。4ファイル合計101項目合格。全国・全年度の網羅、未分析の設問の追加調査は継続課題です。
