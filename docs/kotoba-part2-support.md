# コトバの塔 0.17.0 — 工程⑦ 第11章

工程⑥の帰還記録を読み込み、「第11章へ進む」で再開します。探索に戻った場合は、町の中央右にあるノートを調べ、アオイと救出の相談をしてください。

SCENE73の会話後、町の右下の鍛冶屋へ。倉庫の入口は鍛冶屋の右側です。倉庫の店・宝箱で装備を整え、町の右下の石門から準備道へ進みます。東の石門が塔の地下手前への入口です。

戦闘中の「アオイサポート」は、ヒント・攻撃遅延・誤答への備え・回復・会心補助を各1回使えます。各戦闘で回数が戻ります。選択中も敵ATTACKゲージは進み、解説中に停止します。サポート見出しはクリックまたはSpace／Enterで開閉でき、各ボタンもキーボードで使えます。

鍛冶屋の倉庫が開くと、第2部装備の特殊効果が有効になります。「所持品」で装備を変更してください。買っただけでは効果は発動しません。必要Lv未満の効果は働きません。

準備道の通常敵12体と任意の強敵はLv28→30の育成予算です。Lvは旧記録から継承し、強制補正しません。強敵を倒すと守人の鎧・7（Lv29）を入手し、物資の宝箱が現れます。塔の地下手前で第11章CLEARとなり、町と準備道へ戻れます。SCENE75以降は工程⑧で追加予定です。

開発：`npm run build`。状態検査：`npm test`。操作検査：`npm run test:part2-support-dom`。戦闘試算：`npm run test:part2-support-balance`。

セーブ形式version1と既存の保存キーを継続。会話の自動保存は演出の現在ステップから再開します。
