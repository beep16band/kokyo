# 工程⑥：第10章後半 / 0.16.0

SCENE71「思い出」・SCENE72「明日」の全台詞・話者・順序を正本と照合。工程⑤の旧JSON、Lv、EXP、所持品、G、正答履歴、名前・約束の核を継承。

前半CLEARの「第10章後半へ進む」、または約束の中庭の右上の石門から開始。街道→記憶の書庫→右下の国語ノートを下から調査→右上の階段→追憶の広間中央でメモリア。思い出の核取得後、北の扉→街道→忘却の街→右上の石門→広間中央でトゥモロウ。明日の核取得後、北の扉→帰還路の東の石門→最初の町。町で第10章CLEAR・記録・再開が可能。

メモリアは偽の台詞を戦闘欄に再生し、3解答ごとに内容が変わる。偽物だと明記。国語問題・正答の内容は変更しない。トゥモロウは活動中の戦闘時間20秒ごとに1.00→1.15→1.30→1.45→1.60倍へ攻撃ゲージが加速。上限あり。残量を保持し、解答・解説中は加速時計とゲージが停止。薬・選択中は止めない。敗北後は直前の安全入口へ戻り、再戦の時計は初期化。

既存32px素材・画像と衝突を使う独立8マップ。第1部マップは不変更。書庫と忘却の街に買物・有料回復、往復路を設置。四つの核は重複取得しない。核を取り戻した地域だけ紫霧を弱める。全世界の紫が消える演出はTRUE ENDに残す。SCENE73以降、第11章とサポート・倉庫・特殊効果は未実装。

黎明の斧（6500G/Lv25/攻撃147）、古代の鎧（5900G/Lv26/防御137/固定HP40）を既存計画から有効化。特殊効果は工程⑦まで予約。通常敵20体EXP330、ボス各1100、計8800EXPに対しLv24→28必要8714EXP。Lvを強制補正しない。新通常敵G600～880、ボス1850/2200。新装備代12400Gと回復費をこの地域の収入で確保可能。
