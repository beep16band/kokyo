# 改善点③と第6章（0.8.0）

改善点③は0.7.2で一部対応済みでした。0.8.0で残りを反映し、第6章「忘却の街」を追加しました。

| 改善点③ | 対応 |
|---|---|
| 名前が「主人公」のまま | 台詞・話者を入力した名前へ。元の正本は保持 |
| 壁と階段の説明 | 壁が開き階段が現れたと補足。先生には壁に見えるという正本の台詞は保持 |
| 紋章が壁に見えない | 扉を流用した画像から、石積みの紋章壁へ置換 |
| 赤の対義語 | 一字問題は出題停止。スキャン236〜237頁の二字熟語のみ |
| 不正解で敵にダメージ | 敵HPを減らさず、前の点滅・数字・HP変化を持ち越さない |
| 敵の復活 | 撃破時から5分。移動では復活しない。時刻をJSONに保存。巡回位置も復活時に初期化 |
| 強制エンカウント | 第2〜6章の街道に、一本道を塞ぐ固定守衛。巡回敵も継続 |
| 敵と初期装備 | HP・攻撃・防御を章ごとに強化。武器と防具の更新が効き、後半の店に革のよろいを追加 |
| 問題の難度・四択以外 | 追加分690問を読み入力／語句穴埋めへ。借用した誤答選択肢を表示しない。原本の選択式を保持し、類義語・対義語249問は個別の二字選択肢 |
| 第5章の宿 | 屋根・窓・入口のある128×128の建物。近くでは屋根まで見えるカメラ位置 |
| 中庭の石と紋章 | 別々の画像を生成し、画像と当たり判定を合わせる |

第6章：8マップ、正本SCENE36〜40（全編で1〜40の475台詞を照合）。学校の映像→主人公の焦り→アオイの名を石碑へ→塔へ流れる光→忘名王→北門でCLEAR。寄り道の手紙、宿・店・宝箱・入力問題を含みます。第5章CLEARボタンと北門の両方から接続。第7〜8章は未実装です。

第7章の反転へつなぐため、塔を犯人と考える構造を保持し、塔の真相は明かしていません。光は消えず、文字列として整列して見えます。現実の映像では主人公の姿を教室に描かず、アオイと友人を同じ学生チップで描きます。

保存：JSONのversion1と同じブラウザ保存キーを維持。新しい画像／障害物の中にいた旧記録だけを近くの通行位置へ補正。所持品・成長・図鑑・章旗を保持。C6／C6Eの救済コードを追加。

検証：状態・進行回帰185項目、第5章画面10項目、入力／画像画面3項目、第6章画面5項目、スキャン出題画面3項目が成功。53マップの出入口160経路を実移動で確認。正解・不正解・連続時間切れ・解説中停止・残量再開・IME確定Enter・JSON再開・再訪・報酬重複なしを確認。DOM＋ネイティブCanvasによる検証で、実Chrome／Chromebook端末での確認は未実施です。

画像生成はbuilt-in image_genを使用。完成素材は `assets/inn_house_v2.png`（128×128）、`assets/stone_tablet_v2.png`（64×64）、`assets/emblem_wall_v2.png`（128×128）。縦横比・透明度を保った最近傍変換。旧素材は保存しています。最終プロンプトは[生成素材の記録](kotoba-feedback3-assets.json)に収録。
