# コトバの塔 ― 入試国語 最終試練 ―

公開版0.9.0：プロローグ＋第1〜7章「ことばの継承者」。第8章・エンディングは次工程。

[ゲームを開く](https://beep16band.github.io/kokyo/kotoba-tower.html)

第6章CLEARから「第7章へ進む」、または北の塔入口で続行できます。言葉の広間→管理記録の間（西の石碑、北東の紋章）→封鎖回廊（西・東の石碑と守衛）→レンの記録→共有ノート→最終扉で第7章CLEAR。

第6章は第5章CLEARから開始できます。石道→忘却の街の西のノート→学校の映像→北東の門→石碑にアオイの名→塔を望む丘→忘名王→北の扉でCLEAR。「目的」で未達成の条件を確認してください。

矢印／WASD／タッチで移動。Space・Enter・単独Shiftで会話・決定。入力問題は入力欄で答え、「回答する」を押します。IME確定中のEnterでは送信しません。

改善点③を反映。宿・石碑・紋章の壁を別画像へ置換。敵を強化し、第2〜6章の街道に固定守衛を追加しました。通常敵は撃破から5分後に復活します。

元の398問＋追加945問を保管し、現在の出題対象は1267問。類義語113問・対義語136問は提供スキャン236〜237頁の二字熟語を底本とします。追加分690問に読み入力／語句穴埋めを導入。ランキングは撤去済みです。

旧版の冒険の記録（JSON）は「所持品」→「冒険の記録を読み込む」から引き継げます。終了時は「冒険の記録をダウンロード」で残してください。ブラウザ保存は同じブラウザで利用します。

画像・コード・問題はHTML内蔵。CDN・外部通信は不要。素材利用条件と検証用データはソースに保持。
