# コトバの塔 ― 入試国語 最終試練 ―

公開版0.7.2：プロローグ＋第1〜5章。第6〜8章は未実装。

プレイ：https://beep16band.github.io/kokyo/kotoba-tower.html

矢印／WASD／タッチで移動。Space・Enter・単独Shiftで会話・決定。「目的」で次に進む条件を確認できます。

ランキング機能は終了しました。問題演習は通常練習のみとなり、得点の外部送信はありません。

原本398問＋追加945問は保管し、現在の出題対象は1267問。類義語113問・対義語136問は、提供スキャン236〜237ページの二字熟語の組み合わせを底本として出題します。対象外76問は出題を止めています。「実直＝律儀」などを修正。タイトルの練習室で範囲優先／範囲のみ／確認済み従来問題を選べます。

旧版の冒険の記録（JSON）は「所持品」→「冒険の記録を読み込む」から引き継げます。終了時に「冒険の記録をダウンロード」で残してください。ブラウザ保存は同じブラウザで利用します。

本編の画像・コード・問題はHTMLに内蔵。CDN・外部通信は不要。素材の利用条件は開発用ソースに保持。
