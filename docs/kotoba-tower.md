# コトバの塔 ― 入試国語 最終試練 ―

公開版 0.7.1：プロローグ＋第1～5章「届かなかった手紙」。

プレイ：https://beep16band.github.io/kokyo/kotoba-tower.html

矢印／WASD／タッチで移動。Space・Enter・単独Shiftで会話・決定。「目的」でミッションの達成状況を確認します。

第4章CLEARの「第5章へ進む」、または第4章の北の門から第5章へ。郵便局の手紙3枚→郵便人へ報告→右上の宿のノート→町の北東の中庭で紙・石・ノートを比較→記録室の紋章→右上の階段→未達の使者→北の扉でCLEAR。

旧版の冒険の記録（JSON）は探索中の「所持品」→「冒険の記録を読み込む」から引き継げます。授業終了時は「冒険の記録をダウンロード」で残してください。ブラウザ保存は同じブラウザで利用します。

原本398問＋テスト範囲の追加945問。重複語句を最優先に出題。タイトルの練習室では範囲優先／範囲のみ／従来398問を選べます。

問題演習専用のランキング挑戦（最大20問）、Firebase連携、教師用参加コード・名簿・得点画面を追加しました。公開表示はID・ニックネーム・正答数。氏名の照合は教師の端末だけで行います。**Firebaseは未接続のため共有ランキングの送受信はまだ使えません。** 通常練習と20問挑戦は利用できます。
