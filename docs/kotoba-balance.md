# 戦闘・成長・経済調整 0.10.0

公開対象：beep16band/kokyo の既存 main / GitHub Pages。基準コミット：59e44136dba53d9633e740ce6299675ef265bd9f（0.9.0）。第8章と結末は今回追加しない。

## 現行版の解析

旧最大HPは60＋5×(Lv−1)、基礎攻撃は12＋2×(Lv−1)。正解ダメージは基礎攻撃＋武器＋レン2−敵guard、最低1。**敵guardは既に実計算に使われていた**。被害は敵attack−防具の防御、最低1。乱数なし。必要EXPは floor(22＋13L＋3L^1.55)、薬は30固定。通常敵は5分復活、ストーリー戦闘は一度だけ。第4・5章も第3章の武器・防具が店に並び、成長と購入の差が小さかった。

全敵・装備・価格・章別配置は `balance-current-audit.json` に抽出。元データは `reference/before_balance` に保持。旧版で未使用だった装備HP、武器以外の攻撃、防具以外の防御は今回有効化。MP・素早さ・会心/回避・文字列で記載された特殊効果は引き続き自動発動しない。原本の未配置敵・装備も削除しない。

## 計算と成長

双方共通：**max(2, round((1.25×攻撃−0.5×防御)×乱数0.94～1.06))**。乱数は独立した軽微な幅で、最低2。主人公攻撃＝ちから＋装備攻撃＋レン加入時2、防御＝基礎防御＋装備防御。敵のdefenseを使い、旧guardも互換用に保持。敵を主人公Lvへ自動追随させない。

n＝Lv−1。基礎HP＝floor(48＋6n＋0.5n²)、ちから＝round(10＋3n＋0.15n²)、基礎防御＝round(3＋1.5n＋0.06n²)。必要EXP＝20＋8L＋3L²。Lv1～99の明示表を同梱、物語の最終想定はLv18。HPと能力の増分が中盤・終盤で大きくなる。装備HPは別に加算。レベルアップで全回復。

## 章別目標・装備・経済

通常は2～4回、強敵4～7回、バクロ6～12回、章ボス10～20回の正解を設計基準にした。各章の通常EXPは下表。第3章金文字30、第4章強敵90、第7章強敵130など役割で異なる。第1章バクロは22EXP、ブルーム50EXP。

第8章は16→18の計画のみ。店は章ごとの武器・防具＋前の段階を販売し、Lv条件も連動。第4章以降はその章を歩き戦ってから両方を更新する価格。宝箱・寄り道・以前のGの繰越を保ち、後半で必要な通常戦闘は約12回。通常敵を既存の街道・ダンジョンへ追加し、入口から離して配置。地形・NPC・出入口は変更しない。

経済検証：宝箱・寄り道を調べ、毎章有料宿2回＋予備薬3個の費用を確保して両方の装備を購入。第2章の既存無料W003を利用。第7章のボス後320Gは購入前の資金へ算入しない。通常戦闘の目安に対する追加稼ぎは第1～6章0回、第7章1回。この条件で最後はLv16、残G1610。寄り道を省く場合は買い替えの順序を選ぶか、少数の追加戦闘が必要。実生徒のプレイ時間や行動を観測した値ではない。

薬：40＋最大HPの15%（切捨て）回復。店価格は章に応じ20～50G。薬を使っても回答時計は停止しない。

## 敵とボス

速攻型（9～10秒）、高火力型、防御型、耐久型、G型、EXP型を設定。各敵のパラメータを `combatBalance` と実敵データで一致させ、裏の古い上書き値を残さない。ボスは第2章以降、HP半分で攻撃力1.08倍・間隔0.82倍。HPを大量に増やす代わりに準備と回復の判断を求める。適正LvのHP満タンから一問の誤答で倒れない。

**正解でATTACKを満タンに戻さず、次の問題は残量から継続。意味・解説・用例を読んでいる間は完全停止。** 誤答反撃・次問での再充填・同じ問題中の連続時間切れは従来仕様を保持。

## シミュレーションと回帰検証

## 互換性と変更ファイル

旧Lvを維持。最大HPは新成長＋装備から再計算し、現在HP割合を保持（旧HPが正なら最低1）。EXPは旧必要EXPに対する進捗率を新必要EXPへ変換。G・アイテム・装備所有・旗・図鑑・宝箱・撃破・復活期限・保存キーを保持。新しい `balanceRevision=1` で二重変換を防ぐ。再保存・再読込が同一になることを検査。

主な変更：`src/core.js`、`src/app.js`、`src/student-tools.js`、`data/game-data.json`、`data/maps.json`（追加敵のみ）、`data/balance.json`、`build.py`、`index.html`、`package.json`、`tools/balance_data.py`、`tools/balance_encounters.cjs`、`tests/balance*.cjs`、既存テストの期待値/操作補正。ブラウザ版HTMLはこのソースから生成。

公開リポジトリには `kotoba-tower.html`、継続開発用ZIP、調整報告・シミュレーション・経済検証を反映。0.9.0以前のソースZIPと素材は保持。章8/エンディング、ランキング、問題原本の変更は含めない。
