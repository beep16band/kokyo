# 工程3：屋外配置とDIY

島の手帳と案内所に「屋外の家具・DIY」を追加。

- 木のいす（木材3個）、木のテーブル（木材5個）、植木鉢（木材2個）。
- 屋外または案内所で制作。屋外で配置先を向き、メニューから家具を選ぶ。
- 向かいの配置済み家具を決定で調べ、90度回転・回収。回収して再配置可能。
- 草地のみ、全島で最大60個。道・水・境界・建物周辺・施設・人の目的地・到着地点を保護。設置前後の到達可能マス数を比較し、通路が切れる配置を拒否。
- 屋外の家具は当たり判定を持ち、3D・軽量2Dで表示。屋内家具と別の在庫を使用。
- state.island.diy/outdoorへ加算保存。旧通貨・屋内家具・発展度の計算は維持。
- 通常版とオフライン版を更新。

検証：island_diy_quality.cjs 6/6、island_rules_quality.cjs 13/13、構文・diffチェック合格。Node VMによるロジックとセーブ再読込の検証。実機Chromebook・スマホの操作確認は未実施。
