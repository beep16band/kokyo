## 主な変更ファイル

- `update-boot.js`：初期化前の旧セーブ原文を確保。
- `town-data.js`：価格・作物・料理・住民・施設・8章の定義。
- `scene3d.js`：独自3Dモデル、カメラ、アニメーション、軽量2Dキャラクター、WebGL回復経路。
- `town-life.js`：生活・経済・追加NPC・追加地区・移行処理・クレー。
- `town-quests.js`：共通クエスト、学習、季節、エンディング、UI入口。
- `core.js`：保存例外の修正、作物の許可リスト/区画数/初期定義の拡張、季節関数の差替え可能化。全面書換えではありません。
- `index.html` / `offline.html`：読込順と単一ファイル版。
- `vendor/three.min.js` / `vendor/THREE-LICENSE.txt`：Three.js 0.160.1をローカル同梱。
- `assets/town-jp.woff` / `assets/TOWN_FONT_LICENSE.txt` / `tools/subset_font.py`：全UI文字を含む日本語フォント。久庵・料理等の新しい文字の欠落を修正。
- `tools/audit_phase1.cjs` / `tools/update_quality.cjs`：再現可能なブラウザ検証。

## 制作したグラフィック

建物、三角屋根、窓、植木鉢、樹冠/果実/幹、水の波紋、橋、畑、道具、虫、2頭身前後の主人公と住民、教師の眼鏡・体格・笑顔、まつり飾りは本作用のプロシージャル形状です。モデルはコードから生成し、GLBや外部モデルの取得は不要です。モデルと歩行は方向が一致するよう共有座標を使います。既存作品のキャラ・音楽・テクスチャは使っていません。

町の屋外は3D化しました。室内の家具配置画面等は既存の2Dを維持しています。タッチ端末は安定性優先で2Dを初期設定とし、3Dを設定で選べます。2Dでも主人公・先生の外見、まつり飾り、進行状況は反映します。

## セーブの互換性

保存キーは`kotoba_shop_v1`のまま。既存の数値・配列・履歴は引き継ぎ、新機能は主に`state.expansion`へ追加し、`saveSchema=4`で識別します。新規のみ500G、旧ゲームの所持金は上書きしません。旧expertは現在の選択をhardへ移しますが、回答履歴と累計は旧レベル名のまま保持します。

## 追加改善：描画の軽量化と収支検証（2026-10-18）

開発ブランチ `dev/kotoba-shop-performance-20261018` で実施。町の繰り返し形状を、形状・色ごとのInstancedMeshに集約しました。元の階層を保持して歩行・道具・虫・作物の位置と表示状態を転送するため、操作・当たり判定・セーブ形式の変更はありません。地区変更時には古いインスタンス用GPUバッファと固有形状を解放し、共有形状は再利用します。

同じ町の場面をソフトウェアWebGLで比較した結果：

| 指標 | 改善前 | 改善後 |
| --- | ---: | ---: |
| 描画コール | 248 | 54（約78%減） |
| 三角形 | 52,916 | 55,604 |
| バッチ化あり/なしの画素差（RGB差8超、256×160） | — | 0% |

集約に伴い画面外の一部もまとめて描くため、三角形は約5%増えています。描画コール削減をFPS向上率とは扱いません。短時間のソフトウェア計測は実行負荷で変動し、Chromebookの30FPS達成を証明するものではありません。

`tools/performance_quality.cjs` で描画コール、画素一致、12回の地区変更後の形状数、バッファ解放イベント、メニュー中の再描画抑制、WebGL喪失時の2D復帰とセーブ維持、実行時例外を検証。町/川の形状数は5/3で推移し、再訪しても増加しませんでした。

`tools/economy_quality.cjs` は30分相当の時計を使う収支シミュレーションです。魚6匹（3匹を50Gで店舗販売、3匹を35Gで直接売却）、虫4匹、薬草1個、貝殻1個、スープ1個を販売。スープ材料40Gを購入し、売上470G・純増430G（500→930G）、売れ残り0個、再読込後の残高一致を確認しました。2分ごとの行動に移動・会話・失敗を含むと仮定し、道具は開店セットで入手済みと想定しています。捕獲数はテスト用入力であり、人が30分遊んだ捕獲率・収入の実測ではありません。価格の変更や収入上限は加えていません。

今回の変更ファイルは `scene3d.js`、`index.html`（キャッシュ識別子）、`offline.html`、この報告書、および上記2本の検証スクリプトです。グラフィック素材の追加や既存セーブの再移行はありません。引き続き実機FPSと人による30分通しプレイが残課題です。

既存監査22/22、全機能統合20/20、描画品質7/7、収支4/4の計53項目が合格しました。各ブラウザ検証の実行時例外は0件です。
