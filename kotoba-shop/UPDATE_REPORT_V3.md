## 主な変更ファイル

- `update-boot.js`：初期化前の旧セーブ原文を確保。
- `town-data.js`：価格・作物・料理・住民・施設・8章の定義。
- `scene3d.js`：独自3Dモデル、カメラ、アニメーション、軽量2Dキャラクター、WebGL回復経路。
- `town-life.js`：生活・経済・追加NPC・追加地区・移行処理・クレー。
- `town-quests.js`：共通クエスト、学習、季節、エンディング、UI入口。
- `core.js`：保存例外の修正、作物の許可リスト/区画数/初期定義の拡張、季節関数の差替え可能化。全面書換えではありません。
- `index.html` / `offline.html`：読込順と単一ファイル版。
- `vendor/three.min.js` / `vendor/THREE-LICENSE.txt`：Three.js 0.160.1をローカル同梱。
- `assets/town-jp.woff` / `assets/TOWN_FONT_LICENSE.txt` / `tools/subset_font.py`：全UI文字を含む日本語フォント。久庵・料理等の新しい文字の欠落を修正。
- `tools/audit_phase1.cjs` / `tools/update_quality.cjs`：再現可能なブラウザ検証。

## 制作したグラフィック

建物、三角屋根、窓、植木鉢、樹冠/果実/幹、水の波紋、橋、畑、道具、虫、2頭身前後の主人公と住民、教師の眼鏡・体格・笑顔、まつり飾りは本作用のプロシージャル形状です。モデルはコードから生成し、GLBや外部モデルの取得は不要です。モデルと歩行は方向が一致するよう共有座標を使います。既存作品のキャラ・音楽・テクスチャは使っていません。

町の屋外は3D化しました。室内の家具配置画面等は既存の2Dを維持しています。タッチ端末は安定性優先で2Dを初期設定とし、3Dを設定で選べます。2Dでも主人公・先生の外見、まつり飾り、進行状況は反映します。

## テスト結果とその限界

- 予備監査時は20項目中18合格。保存例外2件を修正して20/20。
- 3D導入後、従来の移動・衝突・店舗・釣り・網・保存・JSON失敗時・単一HTMLを含む22項目が合格。
- 施設/生活/NPCを接続した段階の14項目が合格。
- 統合テストは、3難易度、Gと学習ポイントの分離、季節報酬、8章の実際の達成条件/報告、報酬重複防止、自由生活復帰、旧expertと新作物/新区画/新地区の再開を確認。
- PC相当のChromiumで実3Dを目視確認。描画/2Dキャンバスの寸法一致、約5.4万三角形・約250描画コール（町の一場面、内容で変動）。これはFPSの実機保証ではありません。
- 390px幅タッチ相当で横スクロールなし、画面ボタンでダッシュ切替、クレーのSpace操作を確認。
- 日本語フォントの字形表に久・庵・料・理・阪等があることを確認。
- 単一HTMLはHTTPリクエストなしで起動できることを回帰確認。

8章のテストは、章の完了フラグを直接書き換えず、会話、商品販売、学習（解答例利用）、釣り/網の判定、料理/配達、模型、依頼、準備を呼び出し、その達成条件を通して進めました。時間待ちは自動テスト用に短縮しています。人による長時間の通しプレイを代替するものではありません。

## セーブの互換性

保存キーは`kotoba_shop_v1`のまま。既存の数値・配列・履歴は引き継ぎ、新機能は主に`state.expansion`へ追加し、`saveSchema=4`で識別します。新規のみ500G、旧ゲームの所持金は上書きしません。旧expertは現在の選択をhardへ移しますが、回答履歴と累計は旧レベル名のまま保持します。

移行前原文を`kotoba_shop_before_v3`に確保します。新しい建物で旧位置が塞がれた場合のみ、最寄りの歩ける位置へ移します。新地区・新作物・24区画の再開は旧初期化処理に消されないよう修正済み。代表的な合成データで確認しましたが、あらゆる破損データや全世代の全組合せについて「互換100%」とは断言しません。

公開先は引き続き `https://beep16band.github.io/kokyo/kotoba-shop/`。公開の完了とコミットIDは最終回答で報告します。

- Chromebook/Windows/iPad実機、Safariの実機試験は未実施。Chromebookでの通常探索30FPSは目標であり、実測合格ではありません。
- 30分間の自由生活による300〜600Gの実測調整は未完了。基準価格と販売待ち時間はデータ化してあります。
- 3Dの室内化、GLBへの書出し、より多様な手描き水彩テクスチャは今後の品質向上候補。今回の屋外は実3Dであり、3D風の平面画像ではありません。
- 洞窟は明示された将来拡張用の入口のみです。
- 季節/月次コンテンツ・住民依頼・会話は初期セットです。各月固有の大規模行事、競技会の多人数順位表などは含みません。
- 今後新しい漢字をUIに追加する場合はフォントのサブセットも再生成します。

本番公開前には既知の進行不能・保存破壊・実行時例外を残さず、上記の実機/バランス未検証は完成済みと扱わない方針です。
