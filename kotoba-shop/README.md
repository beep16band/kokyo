# ことばのまちと小さなお店 ― こもれびの旅 v2.0

完成版v1.1の生活・国語システムを引き継いだ拡張版です。

## 起動

このフォルダをそのまま配置して `index.html` を開きます。`assets` と各JS・CSSを一緒に置いてください。相対パスのみで動作し、ゲームから外部サービスへの通信は行いません。

GitHub Pagesの配置先：`/kotoba-shop/`。

[1ファイルのオフライン版](offline.html)もあります。ブラウザからファイルとして保存して開くと、画像やフォントを含めて通信なしで遊べます。

## 操作

- 矢印キー：短押し1マス、長押し連続歩行。1マス190msの一定速度です。
- Space／決定：話す・調べる。歩いている途中の決定は、マスに着いてから実行します。
- M／メニューボタン：8カテゴリのメニュー。
- Esc：閉じる。メニューや選択肢はTab・Enterでも操作できます。
- タッチ画面：画面下の4方向と決定ボタン。
- お店・自宅の扉へ進むと入れます。室内下中央の出口から元の地区へ戻ります。

## 生活・国語

仕入れ・倉庫・陳列・注文・会計・評判・設備・依頼・家具・模様替え・壁と床・図鑑・栽培・産直・釣り・虫取り・住民イベント・季節行事を引き継いでいます。お店の操作は「メニュー→お店」、模様替えは自宅で「持ち物→部屋の家具・模様替え」、畑の手入れは農園で行います。

「やさしい・ふつう・むずかしい・激ムズ」、ふりがな、学習履歴、教師用レポートは維持しています。「メニュー→学習記録」または「設定」から開けます。遺跡の石碑、探索先の依頼も履歴に記録します。例を使ってもゲームを続けられます。運動操作の失敗は国語の誤答に数えません。

## セーブ移行と復元

保存キーは `kotoba_shop_v1` のままです。旧版の所持金、在庫、家具、畑、図鑑、好感度、思い出、学習履歴を維持します。旧屋外位置は町の安全な広場へ移し、旧屋内位置は引き継ぎます。拡張版の屋外位置は `worldPosition` に別途保存します。

初回移行時の控えを端末内の `kotoba_shop_pre_world` に保存します。「メニュー→セーブ」でJSONを書き出し・読み込みできます。「端末内の控えに戻す」でバックアップを復元できます。リセットも確認後に実行し、直前の控えを残します。

**ローカルHTMLとGitHub Pagesは保存領域が異なります。** ローカルの旧版から移す場合は、旧版の設定からJSONを書き出し、新しいサイトで読み込んでください。同じブラウザでも、異なるURLの保存領域を自動で読み取ることはできません。

## 公開と他の教材

変更対象はこの `kotoba-shop/` 配下のみです。リポジトリのトップページ、コトバの塔、コトバクエスト、他の教材のファイルには変更を加えません。

素材の情報は [CREDITS.md](CREDITS.md)、選定理由は [ASSET_REVIEW.md](ASSET_REVIEW.md)、テストの結果と限界は [TEST_REPORT.md](TEST_REPORT.md) を参照してください。

## ミニマップ・選択操作（2026-10-16）

- 屋外の右上に、北が上の地区地図を表示。赤い丸が自分、黄色の四角が建物、白い矢印が地区の出入口です。
- 地図をタップすると、施設・調べる場所・隣の地区への出口を目印（★）にできます。到着は隣のマスまでで表示します。目印と地図の開閉状態はセーブされます。
- Nキーまたは地図のボタンで開閉。室内・会話の選択中・メニュー中は非表示です。
- 選択肢の末尾に（1キー）などを表示。1〜9、0、A〜Zの順に割り当てます。表示されたキー、タップ、矢印で選んでEnter／Space、Tab→Enterで選べます。文章の入力中は文字入力を優先します。
- 同梱のoffline.htmlも同じ機能を含みます。

## 基本の物語と目標

ハルは、動物たちの暮らすこもれびタウンで小さなお店を営みます。注文を読み、住民の話を聞き、依頼に応えることで、品ぞろえと人のつながりを育てます。

最初は仕入れ・陳列・最初の接客。次に住民との交流と周辺9地区の探索。中期目標は評判60の「町の人気店」です。その後も住民の思い出、季節行事、図鑑、家具、遺跡の石碑を楽しめます。固定の最終章やエンディングは実装されていません。国語の解答例を使っても暮らしを続けられます。
