# ことばのまちと小さなお店 ― こもれびの旅 v2.2

完成版v1.1の生活・国語システムを引き継いだ拡張版です。

## 起動

このフォルダをそのまま配置して `index.html` を開きます。`assets` と各JS・CSSを一緒に置いてください。相対パスのみで動作し、ゲームから外部サービスへの通信は行いません。

GitHub Pagesの配置先：`/kotoba-shop/`。

[1ファイルのオフライン版](offline.html)もあります。ブラウザからファイルとして保存して開くと、画像やフォントを含めて通信なしで遊べます。

## 操作

- 矢印キー：短押し1マス、長押し連続歩行。通常155ms・ダッシュ95msで1マス移動します。
- Space／決定：話す・調べる。歩いている途中の決定は、マスに着いてから実行します。
- M／メニューボタン：8カテゴリのメニュー。
- Esc：閉じる。メニューや選択肢はTab・Enterでも操作できます。
- タッチ画面：画面下の4方向と決定ボタン。
- お店・自宅の扉へ進むと入れます。室内下中央の出口から元の地区へ戻ります。

## 生活・国語

仕入れ・倉庫・陳列・注文・会計・評判・設備・依頼・家具・模様替え・壁と床・図鑑・栽培・産直・釣り・虫取り・住民イベント・季節行事を引き継いでいます。お店の操作は「メニュー→お店」、模様替えは自宅で「持ち物→部屋の家具・模様替え」、畑の手入れは農園で行います。

「やさしい・ふつう・むずかしい・激ムズ」、ふりがな、学習履歴、教師用レポートは維持しています。「メニュー→学習記録」または「設定」から開けます。遺跡の石碑、探索先の依頼も履歴に記録します。例を使ってもゲームを続けられます。運動操作の失敗は国語の誤答に数えません。

## セーブ移行と復元

保存キーは `kotoba_shop_v1` のままです。旧版の所持金、在庫、家具、畑、図鑑、好感度、思い出、学習履歴を維持します。旧屋外位置は町の安全な広場へ移し、旧屋内位置は引き継ぎます。拡張版の屋外位置は `worldPosition` に別途保存します。

初回移行時の控えを端末内の `kotoba_shop_pre_world` に保存します。「メニュー→セーブ」でJSONを書き出し・読み込みできます。「端末内の控えに戻す」でバックアップを復元できます。リセットも確認後に実行し、直前の控えを残します。

**ローカルHTMLとGitHub Pagesは保存領域が異なります。** ローカルの旧版から移す場合は、旧版の設定からJSONを書き出し、新しいサイトで読み込んでください。同じブラウザでも、異なるURLの保存領域を自動で読み取ることはできません。

## ミニマップ・選択操作（2026-10-16）

- 屋外の右上に、北が上の地区地図を表示。赤い丸が自分、黄色の四角が建物、白い矢印が地区の出入口です。
- 地図をタップすると、施設・調べる場所・隣の地区への出口を目印（★）にできます。到着は隣のマスまでで表示します。目印と地図の開閉状態はセーブされます。
- Nキーまたは地図のボタンで開閉。室内・会話の選択中・メニュー中は非表示です。
- 選択肢の末尾に（1キー）などを表示。1〜9、0、A〜Zの順に割り当てます。表示されたキー、タップ、矢印で選んでEnter／Space、Tab→Enterで選べます。文章の入力中は文字入力を優先します。
- 同梱のoffline.htmlも同じ機能を含みます。

## 基本の物語と目標

ハルは、動物たちの暮らすこもれびタウンで小さなお店を営みます。注文を読み、住民の話を聞き、依頼に応えることで、品ぞろえと人のつながりを育てます。

最初は仕入れ・陳列・最初の接客。次に住民との交流と周辺9地区の探索。中期目標は評判60の「町の人気店」です。その後も住民の思い出、季節行事、図鑑、家具、遺跡の石碑を楽しめます。固定の最終章やエンディングは実装されていません。国語の解答例を使っても暮らしを続けられます。

## 最初のチュートリアル（2026-10-16）

新規ゲームでは、難易度を選び「町の暮らしへ」を押したあと、フクじいの案内が表示されます。7段階で、実際の移動・地図の目印・入店・在庫確認・陳列・接客・翌日への進行を体験します。今することはゲーム画面の下に表示されます。

ガイドボタン／Tキーで説明を読み直せます。「あとで」「説明なしで遊ぶ」、練習の省略、中断に対応しています。進み具合はセーブされ、中断後も続きから練習できます。再練習でコイン・持ち物・日付・評判をリセットしたり、追加の報酬を発生させたりしません。

既存セーブでは案内を自動表示しません。**メニュー → 設定 → はじめての練習**から開始できます。完了後も同じ場所から練習し直せます。オフライン版にも同梱しています。

## v2.1 移動・採集アクション（2026-10-16）

- 通常歩行は155ms／マス、ダッシュ95ms／マス。Shiftを押しながら歩くか、画面の「走る」をタップして切り替えます。1マスの途中では速度を変えず、次のマスから反映します。NPCは260ms／マス。
- 虫はマップ上に現れ、羽ばたく・歩く・飛び出す動きをします。近くで虫の方を向き、Bまたは「網を振る」。網を振り終わるまで立ち止まります。季節・地区・朝昼夕で出現する種類が変わります。
- 川・湖の水辺でFまたは「釣り」。竿と浮きを見て待ち、浮きが沈んで「！」が出たらSpace／Enter／決定／「合わせる」。魚ごとに合わせる時間が異なり、早すぎても遅すぎても何も失いません。Escで中断できます。
- メニュー → 設定 → 文字・動き・操作設定 → アクションの難しさ・補助・音。操作は「ゆっくり・標準・挑戦」、補助ONで合わせる時間を3秒延長し、網の判定を広げます。国語の4段階とは独立しています。音は合成効果音で、OFFでも視覚の合図があります。
- 主要地点の旗に近づくと「旅の拠点」に登録されます。J、またはメニュー → まちの地図 → 旅の拠点・近道から移動。11拠点は実際に近づいた場所だけが登録されます。従来の訪問済み地区への移動も維持しています。
- 森―農園、丘―湖、町―遺跡の裏道を追加。両端の入口を歩いて発見すると通行可能になります。
- 釣り・虫取りのたびに国語問題は出ません。図鑑には季節・場所・時間の観察メモを追加。図鑑・手帳 → 生きものの観察メモでは任意の読解活動ができます。接客・畑・依頼・会話などの学習は継続します。
- 捕獲物はこれまでと同じ図鑑・持ち物へ入り、売却・住民への贈り物・依頼に使用できます。旧セーブは既存項目を引き継ぎ、新設定だけ補完します。

Chromebook実機での確認は未実施です。Chromiumでキーボード・360px幅のタッチ操作・オフライン版・セーブ移行を検証しています。

## v2.2 温かい町のグラフィック（2026-10-16）

`cozy.js` にオリジナルのCanvas描画を追加。建物、住民7人、木3種、石、花、道、水辺、橋、柵、看板、井戸、虫を柔らかい形・配色で描きます。屋外9地区へ適用。室内の既存レイアウト・家具は引き継ぎ、主人公と住民の描画を共通化しています。

木の微かな揺れ、水の波紋、光の粒は「動きを減らす」で静止します。描画はキャッシュし、外部ライブラリ・追加画像・外部通信は不要です。3Dモデルを使わず、陰影のある2D描画で立体感を出しています。移動・当たり判定・学習・採集・セーブのコードは変更していません。
