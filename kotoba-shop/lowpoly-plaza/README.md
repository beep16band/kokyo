# 中央広場：操作できる3D人物試作

開発ブランチ `dev/lowpoly-plaza`。本編への統合前の独立した試作。最新版はユーザー提供の4人のキャラクターシートを美術基準とする。

## 操作

`index.html` を同梱ファイルと一緒にブラウザで開く。外部CDNやネットワークで取得するモデルは不要。

- 移動: 矢印 / WASD / アナログスティック。Shiftまたは「走る」を押している間ダッシュ。
- 会話: E / Space / 「話す・調べる」。先生、他の3人、商店入口に近づく。
- 画面の設定: 4人の切替、服、帽子、表情、四季、時刻、投影、俯角、描画品質。
- 表示する範囲の「顔と服をじっくり見る」で実際のモデルを拡大。カメラを45°ずつ回して前後左右を確認できる。
- 「計測を見る」: FPS、描画数、三角形数、CPU p95、フレーム間隔p95。20秒歩行計測とJSON保存。

## 4人のモデル

| 表示名 | 基本の外見 |
| --- | --- |
| ひより | 茶色の短い二つ結び、花飾り、白と桃色の上着、赤いリボン、紺のスカート、桃色の靴とバッグ |
| そら | 紺色の束感のある髪、灰色のパーカーと黒系の上着、黒い長ズボン、スニーカーとバッグ |
| つき | 薄紫のボブ、花を付けた黒いベレー帽、紫のリボン、黒系の上着、チェック風のスカート、黒い靴とバッグ |
| 男の子② | 茶色の髪、緑のジャケット、クリーム色のパーカー、黒い短パン、緑の靴と暗色のバッグ |

4人目の名前は参考画像に記載がないため未設定。モデルの内部IDは既存の `girl` / `boy` に加えて `tsuki` / `green`。

約2.3〜2.5頭身を目安に、顔・髪・体・手足・衣装・靴・バッグを実際の3D形状で構成。髪は滑らかな曲線に沿う毛束、目は色付きの虹彩と2点の反射が入ったオリジナル256×256テクスチャを、頭部に固定した曲面へ貼る。顔全体やキャラクターをカメラへ向けるビルボードは使用しない。

各モデルに参考画像の服 / カジュアル / アウトドアの3着、基本 / なし / キャップ / 麦わらの帽子切替、通常 / にっこり / びっくりの3表情。つきの基本帽子はベレー帽。他の3人の基本は帽子なし。選択を切り替えても各人の試作内の着替えは保持する。ページ再読み込みで初期状態に戻る。

阪口先生は従来の眼鏡フクロウの立体モデルを維持。建物・樹木・地形も3D。草・道の模様は32×32、看板は128×128、顔パーツは256×256。既存作品のキャラクターやモデル・テクスチャは使用していない。

## 性能と検証

平行投影、透視40°/55°、俯角45°/55°、人物確認用18°を比較可能。季節で地面・木・花・屋根・積雪、時刻で空・照明・ランタンが変化する。

静的形状と頭部・衣装を材質別に結合。内部最大960px、高画質1280px、軽量640px、DPR=1。リアルタイムシャドウとポストエフェクトは使用しない。初期の可視形状は251メッシュ、176,752三角形（全4人と先生と広場、カメラのカリング前）。帽子や服によって変化する。

コード側の実Three.js形状・入力シミュレーション24/24項目合格。4人それぞれの操作、衣装、帽子、表情、目の反射、移動、衝突、カメラ、昼夜、四季、本編との保存領域の分離を確認。`../qa/lowpoly-plaza-20261024.json` 参照。

確認用クラウドブラウザは GL_VENDOR / GL_RENDERER = Disabled でWebGLを起動できなかった。GPUでの描画とChromebook実機での30FPSは未確認。実機では各投影方式・標準/軽量・昼夜/冬で20秒歩行計測し、画風・操作感・実測速度を確認してから町へ展開する。

`../qa/lowpoly-plaza-portraits.png` はゲームと同じモデルをCPUで描画した形状確認用画像。ブラウザのスクリーンショットではなく、照明・影・アンチエイリアス等は実ゲームと異なる。

検証: `node kotoba-shop/tools/lowpoly_plaza_quality.cjs --portraits`

## 人物の滑らかな3D化（2026-10-24）

ユーザーの新方針に従って、人物のローポリゴン制約を解除。顔32×24分割、通常の丸い形状24×16分割、髪16区間×10断面へ変更。髪は平行移動フレームで捻れを除去し、輪郭と陰影を滑らかにした。顔と服の縁・バッグ・靴も丸め、人物にはPhong材質を使用。背景の地形・建物・木・道・材質・配置・季節処理は変更していない。背景生成部のSHA-256一致を検証している。

膝を独立して曲げる歩行、胴体の揺れ、まばたきを追加。操作する人は画面上部ですぐ選べる。選択後はゲームへフォーカスを戻し、そのままキーで操作できる。地面のクリック／タップは3Dのレイと地面の交差位置まで歩く。障害物の迂回経路探索は行わず、壁に阻まれると停止する。キャラクター自体のクリックでも操作対象を切り替えられる。キーボードまたはスティックの入力でタップ移動を中断する。

`play-3d.html` はライブラリ・モデル・CSSを含む単一ファイル。保存後はネット接続なしでブラウザから開ける。WebGL対応は必要。本編のセーブは読み書きしない。生成は `python3 kotoba-shop/tools/build_plaza_offline.py`。同梱元ファイルを変更したら再生成する。

この版でも確認用ブラウザのWebGL起動は失敗しており、実GPUの描画・実機性能は未確認。コード側では24項目合格。単一HTMLのスクリプト構文と外部依存の除去も検証した。

## キャラクター非表示の修正（2026-10-24）

実ブラウザでCanvasRenderingContext2D.ellipseが6引数で呼ばれているエラーを再現。口の内側を描く呼出しで開始角0が不足しており、ひよりの生成時に初期化が中断していた。7引数へ修正。従来のNode Canvasは6引数を受理したため、コード側テストが見逃していた。検証用Canvasにもブラウザと同じ引数チェックを加え、全員の全表情を再検証した。

画面に読み込みエラーを表示する処理と「互換表示」ボタンを追加。WebGL起動失敗時は同じ3Dの頂点・面・カメラをCPUで投影し、深度バッファとUVを使ってCanvasへ描画する。キャラチップによる2D代替ではない。互換表示では内部解像度最大540pxと人物の曲面分割数を抑える。照明や滑らかさはWebGL表示と異なり、速度は端末に依存する。通常は従来のWebGLを優先する。

確認用Chromeで互換3D表示の起動、4人と先生の描画、地面タップによるそらの移動、ひよりへの切替、びっくりの表情、カジュアルへの着替え、人物の拡大表示を実際に確認。`../qa/plaza-browser-display-fixed.jpg` は実ブラウザの記録。`../qa/plaza-browser-display-fixed.json` に手順を保存。GPU版とChromebook実機の性能は引き続き未確認。コード側26/26項目合格。
