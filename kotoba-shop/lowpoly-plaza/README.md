# 中央広場のローポリゴン3D試作

開発ブランチ: `dev/lowpoly-plaza`。本編の変更・統合は行わない。

## 操作と比較

`index.html` をブラウザで開く（依存ファイルは同じフォルダ）。外部CDN・ネットワーク取得・ビルドは不要。公開プレビューではそのまま遊べる。

- 移動: 矢印 / WASD / 表示アナログスティック。Shiftまたは「走る」を押している間だけ走る。
- E / Space / 「話す・調べる」: 阪口先生・もう一人の主人公・商店入口を調べる。
- 「画面の設定」: 主人公2人の切替、春夏秋冬、時刻、自動時間進行。
- 投影: 平行投影、透視40°、透視55°。俯角45°/55°、45°ずつ回転、広場全体/人物を近くで比較。
- 「計測を見る」: FPS、描画数、三角形数、内部解像度、CPU時間p95とフレーム間隔p95。
- 「20秒の歩行計測」: 同じ歩行コースを20秒自動走行。JSONを保存できる。タブ移動・主人公交代・位置リセットで中止。

## オリジナル素材

主人公の服・配色・帽子・髪型は `town-characters.js` の2D案を引き継ぐ。男の子は青いオーバーオールと麦わら帽子、女の子は桃色の服と二つ結びと麦わら帽子。阪口先生は `island-data.js` / `island-art.js` の眼鏡フクロウ、カーディガンとクリームの前立て。

全キャラクターは球・低分割円柱・立方体・トーラスを組んだ奥行きのある立体。頭、体、腕、脚に独立の変換を持つ。約2.3〜2.5頭身。キャラクター用スプライト・ビルボードは使用しない。建物・樹冠・幹・地面・道も実際の3Dメッシュ。既存作品のモデル・地形・キャラクター・画像は使用していない。

草地と道の模様はオリジナル32×32ピクセルをコードで作成しNearestで拡大。看板のみ可読性のため128×128。高精細PBR、反射、法線マップ、ポストエフェクトを使用しない。三本の樹冠、地面、屋根、花、空と照明が季節・時刻に応じて変化。冬は樹冠に積雪、夜はランタンが発光する。

## 性能方針と検証状況

静的メッシュを材質別に結合、頭部を個別に結合、影は平面の柔らかな影、リアルタイムシャドウなし。内部横幅は標準最大960px、軽量最大640px、DPR=1。上限30FPS、比較用60FPS。画角切替は同じ注視面の大きさを維持する。

コード側の実ジオメトリと入力シミュレーション16/16項目合格。シーン全体109メッシュ、25,492三角形（冬の積雪表示で小幅増加）。GPUで実際に可視の描画数はカメラのカリングで減る。QA JSONは `../qa/lowpoly-plaza-20261024.json`。

確認用クラウドブラウザでは、GL_VENDOR / GL_RENDERER = Disabled によりWebGLコンテキスト作成に失敗。実ブラウザでの3D表示・GPU時間・Chromebook実機での30FPSは未確認。Nodeで実Three.jsメッシュ、入力、衝突、カメラを検証し、CPUラスタライズによる形状点検を行った。これはブラウザや実機の代替合格ではない。

採用前に対象Chromebookで標準/軽量、3投影方式、昼/夜/冬で各20秒を測定する。目安: 平均29FPS以上、フレーム間隔p95 40ms以下、操作の取りこぼし・壁抜けなし。画風・操作感・実機速度の確認後に本編への統合を判断する。

## 本編とセーブの維持

本編のHTML/JSや既存のセーブを変更しない追加ページ。本編のスクリプトを読み込まず、localStorage / IndexedDB等の保存領域も読み書きしない。試作中の移動や会話で本編の購入・学習・島の進行は変わらない。試作には学習・買い物・屋内などの本編システムを重複実装しない。
