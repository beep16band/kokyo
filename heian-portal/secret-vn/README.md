## 遊び方

非公開ページの「試験プレイ」から開始。クリック／タップ／Space／Enter／→で全文表示と次の会話へ。←で戻る、1〜4で選択、Lで履歴。問題は会話枠に4択で表示され、正解するまで先へ進めない。問題の本文は画面上部に常に表示。

既読送りは読了した会話のみ。クイズと未読会話で停止。AUTOもクイズで停止。手動保存は自動保存とは別スロット。章末に回想・学習記録を表示。
