# 通常版オープニング更新案：花びらダンス

## 状態
**実装・自動テスト済み、公開前。** 音源のWeb公開・編集の許諾条件が確認できていないため、MP3は公開リポジトリへ追加していない。本番の通常版オープニングは変更していない。

参照した指示書：`WORK_花びらダンス_差替え実装指示.md`。同書の「音声公開権を確認」に対応する制作元・利用規約・許諾の記録が未確認。利用可能な音源であることが確認できたら、MP3を配置して本番へ反映する。

## 変更
- 15カット、105秒。配分は7,5,6,8,8,8,8,7,4,4,4,4,8,8,16秒。
- 各画像のCSS尺も一致させ、人物と名前を反対方向から導入。読み方・台詞は遅れて表示。
- 音がONの場合は音声の現在位置を映像とアニメーションの共通時計にする。読み込み待ち、一時停止、タブ非表示からの再開で映像だけが先行しない。
- 終盤8秒で映像・音量をともにフェード。音量スライダーはフェード量に乗算。
- 音声の自動再生拒否・読み込みエラー時も無音で映像を進め、再生ボタンを残す。
- 再視聴・スキップ・停止時に音声位置とフェードを初期化。
- 開始時は無音。音をONにする操作で音声を再生する。
- 桜の演出は通常版OP内だけ。隠し章へは追加しない。
- 通常教材・本編・保存キーは変更なし。OPのHTML・CSS・スクリプトを除いた部分が変更前と完全一致することを確認。

## テスト
仮想DOMと音声APIのテスト8項目が通過：105秒終端、音声時計、停止再開、音量とフェード、非表示タブ、スキップと再視聴、自動再生拒否、バッファ待ち。

MP3実測：105.024秒、160kbps、2,101,038バイト。バンドルの105秒版を使用。旧South Windへの参照は更新案から除去した。

**未確認**：新音源を聴いてのフレーズ境界の微調整、実ブラウザでの新音源再生と105秒通し確認、実機Chromebook・Android・iOS。自動テストだけで映像・音楽の完成とは扱わない。

旧OGGファイルは公開権確認後の本番反映時に、リポジトリ全体の参照確認を行い、共有参照がなければ削除する。現時点では稼働中OPが使用中なので削除していない。
