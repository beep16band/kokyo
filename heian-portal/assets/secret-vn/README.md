# 言の葉の檻 ― 千年の約束 ― 素材第1便

2026年10月14日制作。第1章・第2章を優先する画像素材の納品です。本編の完成・実装を意味しません。既存ポータルのHTML、ゲーム、和歌データ、保存処理は変更しません。

## 内容と使用方法

- BG00〜BG17の18場面。共通の11背景WebP、暗転・彩度のフィルター指定、独立した透過エフェクトを組み合わせます。状態ごとに大きな背景を複製しません。
- 額田王・小野小町・紀貫之・山上憶良・丈部稲麻呂は通常／微笑／驚き／記憶喪失を用意します。
- 湊・茜は通常／微笑／驚きの既存全身素材を再利用し、恐怖／悲しみ／決意を新規制作します。
- ことはは通常／微笑／困惑／悲しみ／恐怖／決意／封印状態。真尋は通常／悲しみ／微笑／決意。
- 墨の侵食・回復の光は独立透過素材です。画像にセリフ・名前・UIを描き込んでいません。
- `preview.html` は素材確認専用です。背景／人物／状態を選び、PC16:9とスマホ9:16の合成を確認できます。既存ポータルからの起動ボタンは追加しません。
- `manifest.json` の相対URLはこのファイルの所在を基準とします。章に必要な背景の `file`、`layers` と人物の該当 `states` だけを読み込んでください。ファイル存在の確認なしに `backlog` を読み込まないでください。
- 背景の `filter` は背景画像だけに適用します。人物や会話枠には適用しません。`layers` は背景と人物の間に置き、`pointer-events:none` を指定します。
- 立ち絵は560×1080（ことはは広い裾を保つため840×1080）の透過キャンバスに整理しています。頭・顔が切れないよう `object-fit:contain` を使ってください。スマホでは中央の人物領域と会話枠を別々に確保してください。
- 回復演出は同じ背景を保持し、フィルターと墨レイヤーの不透明度を変える構成です。本便には本編用のアニメーションプログラムは含めません。

## 解像度と軽量化

原寸PNGと実装用WebPを分けています。背景の実装用サイズは1600×900です。人物は原寸を無理に拡大せず、透過余白・足元の基準をそろえて書き出しました。WebPは画質88から必要時のみ段階的に調整しています。ファイルごとの実サイズ・実寸・SHA256は `asset-list.csv` とmanifestを参照してください。

生成された原寸には高さ941〜1254pxのアトラスも含まれ、高さ1600〜2000pxという推奨マスター仕様は全人物では満たしていません。大画面で顔に大きく寄るカットを作る際は、単体高解像度素材が追加で必要です。画素数の水増しで完成扱いしません。
